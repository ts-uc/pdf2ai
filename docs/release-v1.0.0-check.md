# v1.0.0前の最終確認

2026-10-12、現在のコードに対してローカルの最終確認を実施した。

結合の事前チェックAPIで、選択ページ数と異なる長さのラベルを渡すとIndexErrorになる不具合を修正した。不正なラベルはConversionErrorとして診断し、選択ページ・ラベルのイテレーターは、結合失敗後のページ別診断でも同じ値を使う。回帰テスト5件を追加。

| 確認 | 結果 |
| --- | --- |
| 全自動テスト | 532件成功、既存のSWIG非推奨警告5件 |
| 依存関係 | pip check成功 |
| 配布用wheel | ビルド成功 |
| wheelからの実行 | ソースパッケージへの依存なしでimportと厳密変換成功。4935サブパス、特色4、画像17 |
| 同梱データ | DIC CMYK・DIC Lab・TOYO LabのJSON3ファイルを確認。TOYO2129色の読込成功 |
| 保護ファイル | ai_files全ファイル、DIC／TOYO JSON、XMLパレットのSHA-256一致 |
| 差分チェック | git diff --check成功 |

ビルド確認のためプロジェクトの仮想環境にsetuptoolsとwheelを追加した。製品の実行時依存関係は変更していない。

この確認で、修正後にv1.0.0を妨げる新たな実装不具合は確認されなかった。Windows／Linuxや他の依存バージョンのCIを今回ローカルで実行した結果ではなく、その保証としては扱わない。既知の未対応入力の画像化と、edmondsonの1ページ目の微小な描画差は引き続き存在する。

バージョン番号は変更していない。`pyproject.toml` の project.version と `src/pdf2ai/__init__.py` の __version__ は現在ともに0.1.0。v1.0.0を設定する際は両方を合わせる。

ビルド成果物・検証記録は `output/release-final-check/` に保存した。
