# 単独デスクトップGUIの削除

2026-10-11。Scribus以外のGUIを使わず、保守対象を減らしたいという依頼により削除した。

- Tkの画面、GUI用バッチ処理、専用ランチャー、`--gui`の起動分岐、パッケージのGUIコマンドを削除。
- 単独GUIだけが使っていたキャンセル／進捗コールバックと専用モジュールを削除。単ページ・結合のPython APIからも該当引数を除去。
- GUI専用テスト12件とGUI専用の作業文書を削除。画像・CLI・Scribus・データ保護のテストは継続する。
- GUI配布用のPyInstaller依存とビルド手順、Tk導入案内を削除。
- この仮想環境に残っていたGUIコマンドと、生成済みのGUI関連キャッシュ・パッケージ情報も整理。

Scribusの書き出し設定画面、ページ別／結合、dpi・画像化禁止・裁ち落とし・トンボ・制限時間・ログ設定は維持する。Scribus設定画面に必要なPySide6は維持する。PDF直接変換のCLIと変換エンジンも維持する。

## 検証

- 残る自動テスト290件成功。削除前302件との差12件は単独GUIと専用キャンセルのテスト。
- 統合サンプル14ページ成功。
- CLIランチャーの`--help`成功。パッケージの起動コマンドはCLIのみ。
- Scribus連携スクリプトの`--check`成功。設定画面・書き出しの既存自動テストも成功。
- 現行コード・テストに削除したGUIモジュールの参照がないことを確認。

Tk画面の実機確認は、機能を削除したため残課題から外す。Scribusの実機操作、実制作データ・DIC 448・印刷結果や描画互換性の検証は別の課題として残る。過去の監査・作業記録のTk GUIに関する記述は履歴として残し、冒頭に削除済みと明記する。
