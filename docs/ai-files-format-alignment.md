## 出力処理の変更

| 項目 | 変更 |
| --- | --- |
| 編集データの格納 | Adobeと同じ64KiB単位のZstandardブロックを、PDFのFlateで再圧縮せず保存。AIMetaDataとXMPも無フィルター。通常のPDF内容・画像は圧縮を維持 |
| PostScript文字列 | 日本語名を参照AIと同じUTF-8表記に変更。括弧・バックスラッシュ・制御文字は引き続きエスケープ |
| ヘッダーと設定 | 作成日時、版情報の宣言順、既定のアートスタイル、スタイル一覧、空のシンボル一覧を整備 |
| XMP | Illustrator文書種別、InstantSave無効、RenditionClassを設定。NPagesは参照AIと同じ文書単位の1とし、実際のPDFページ数とレポートのページ数は保持。特色の濃度・成分を小数6桁で記載 |
| XMPプレビュー | PDF用52pxサムネイルとは別に、256pxのJPEGを生成。単ページはArtBox内の作品、結合は全アートボードをプレビュー |
| 不透明CMYKパスのPDF設定 | 非分離・非ノックアウトの冗長なDeviceCMYKページグループを省略し、Adobe出力と同じPerceptualを初期描画インテントに設定。元の明示的なri・ExtGState /RI、オーバープリントは保持。登録済みLab特色にも適用。透明・RGB・画像・グループ効果・プロファイル付きLab特色のあるデータには適用しない |
| 塗りパスのPDF座標 | 連続した不透明な塗りパスを最初の点に対する相対座標へ整理。Adobeに合わせて原点は小数4桁、相対座標は小数3桁に丸める。ページを覆う矩形の塗りはページ境界まで整理。編集用AI座標は変更しない |

CMYKページグループと初期インテントの違いは、MuPDFでの黒・特色の画面表示差にも関係していた。この変更でedmondsonの黒の内部画素がfromai側と一致した。元PDFの暗黙の描画インテントをそのまま維持する処理からの意図的な変更であり、CMYK版の数値や特色定義を変更する処理ではない。

## 複合パスと端数の丸めへの追加対応

残った1ページ目の差を調べ、PDF表示用座標の端数処理と、Illustratorが複合パスの子パスを反転してPDFへ書き出すことによる原点変更を確認した。

- PDF座標の丸めを、Python標準の偶数丸めからDecimalの四捨五入（半端値は正負とも0から遠ざける）へ変更。編集用座標は丸めない。
- 不透明・通常合成・単色の塗り専用複合パスは、編集ストリームへの書き込み時に子パスの順序を反転。IllustratorでPDFへ書き出すと入力PDFと同じ順序になり、PDF側の丸め原点をそろえられる。個々の座標・曲線・始点・閉鎖・輪郭の向きは保持し、Drawingの元リストも変更しない。
- 線、塗りと線の併用、半透明、通常以外の合成、グラデーションには順序変更を適用しない。クリッピングパスの順序も保持。

## 比較用データに固有の差
