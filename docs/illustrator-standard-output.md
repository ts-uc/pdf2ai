# 参考AIに合わせた標準出力の調整

2026-10-12。`dic1_fromai.ai`を参考に、ツール全体の標準出力を調整した。参考用の`dic1_exported.ai`と`dic1_fromai.ai`は変更せず、検証用フォルダーへ新しいAIを生成した。

## 合わせた項目

- 定規単位はポイント。既定アートボード名は「アートボード 1」、元PDFにレイヤーがない場合の既定名は「レイヤー 1」。元PDFにある名前・表示・ロック・印刷属性、結合時のページ番号は保持する。
- レジストレーションスウォッチを追加。実際に使うプロセス色だけをヘッダーへ記録し、特色だけの文書では不要なプロセス色の宣言を省く。
- クリッピング・線・画像・グループ効果のない不透明な塗り図形は、実際の曲線極値から作品範囲を算出し、AIのBoundingBoxとPDFのArtBoxを設定する。アートボードのサイズは変えない。範囲を確定できない構造やページ外の図形では従来の範囲を保持する。
- 単純なCMYK／グレー／特色の不透明な塗りだけで、分離・ノックアウト・オーバープリントがないページでは、不要なCMYKページ透明グループを省く。透明効果、画像、グラデーション、線、クリッピングなどを含む場合は維持する。
- 実際のページ表示から37×52等の小さいPDFサムネイルを生成する。作品の画像化や画像オブジェクトの追加ではなく、ページの`Thumb`として保存する。
- 出力の変更日時、ページのLastModified、XMP日時、文書・インスタンスID、ページ数、透明・オーバープリントの情報を付ける。XMPにも実際のページ寸法・分版名・特色スウォッチとCMYK／Lab値・JPEGサムネイルを記録し、古い表示用情報を更新する。元のタイトル・著者は保持し、タイトル未設定時は出力ファイル名を使う。IDや履歴を参考ファイルからコピーしない。
- 既定値だけの単ページ表示・左から右への表示設定・回転0度の冗長な指定と、旧式のProcSet指定を省く。独自の表示設定は保持する。

## 検証と残る相違

自動テスト359件成功。標準設定、曲線極値、透明・線・クリッピングの保持、ページ外の図形、元タイトル・レイヤー名・表示設定の保持、結合の順序とサムネイル、XMPのDIC CMYK値・TOYO Lab値を確認した。

新規生成した`output/fidelity-check/after/dic1-standard.ai`をIllustrator 30.8.2で開き、参考AIとの形状・描画属性を比較。定規はポイント、既定アートボード名は「アートボード 1」。両方とも閉じた矩形1・頂点4・画像0・文字0、線なし、不透明度100%、オーバープリントなしで一致。DIC 1sのCMYK値と濃度も一致した。元PDF由来の「背景」レイヤー名は保持した。座標には元データとIllustratorの浮動小数点精度による約0.000012pt以内の差がある。

参考AIと新規AIのPDF表示の144dpi比較は、Illustrator再保存前・再保存後の両方で平均画素差0。AI再保存・再オープン後もアートボード1・パス1・画像0を保持した。参考用2ファイルはSHA-256が変更されていないことを確認した。

ツールの出力には実データに基づくサムネイルとXMPを追加したが、Illustratorで再保存すると約48KBとなり、参考AIの約48KBと同程度になる。Illustratorが生成する文字エンジン・プラグイン等の内部情報や保存履歴は、別文書のものを流用せず、本ツールでは生成しない。作成アプリ・編集ストリームの互換表記も既存のCC2020形式を維持する。このためバイト単位で同じファイルになるわけではない。今回の実機比較は1実例であり、全入力・全版への保証ではない。

構造比較：`output/fidelity-check/after/dic1-standard-structure.json`。再保存結果：`illustrator/results-dic1-standard.tsv`。画素比較：`dic1-standard-visual.json`と`dic1-standard-comparison.png`。

## 再点検での追加修正

XMPだけに記録されたタイトルが出力ファイル名で上書きされる経路を修正した。PDF文書情報にタイトルがない場合はXMPのタイトルを使用し、既存XMPタイトルも保持する。

透明・オーバープリントのXMP判定は、実際に使う塗り・線と表示中のレイヤーだけを見るよう修正した。線だけの図形に残る未使用の塗り設定、塗りだけの図形の未使用の線設定、非表示レイヤーの設定による誤判定を防ぐ。画像の全不透明なアルファ値も透過として数えず、通常以外の描画モードは透明処理として記録する。

タイトル保持と塗り・線・表示状態の回帰テスト6件を追加し、全365件成功。参考用AIの変更・Illustratorでの追加再保存は行っていない。
